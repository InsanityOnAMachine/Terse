Searching in Terse

trs --search 

    This searches the current server for the query you provide.
    (So you must be on a server, though you don't hafta be signed in!)
    
    Since this is what you'll use the most, it has a shortcut.
    Just type in 

    trs center div

    to search how to center a div, for example; as long as the first
    word isn't 'help', it'll --search by default.
