Terse!

Here's a list of all the commands in Terse:

trs --search (searching, but there is a faster shortcut!)
trs --stats  (stats of the current server you're on)
trs --pub    (all about publishing posts to the server you're on)
trs --server (all about addin', switchin', and loggin' into servers)
trs --whoami (quick info about yourself)

and finally:

trs help

If you want to know more about any command, hammer out

trs help --pub

for example, to learn more about the --pub command.
